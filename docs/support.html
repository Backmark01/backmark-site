How to save

  1. Open a link, image, video, post, or file in another app.
  2. Tap the iOS Share button.
  3. Choose Backmark. If it is hidden, tap More and add Backmark to Favorites.
  4. Return to Backmark and find the new Memory in your Library.

Saving a screenshot with Back Tap

Run the Backmark Shortcut from Back Tap. The screenshot is stored as the Memory preview, and visible text is recognized on the device so it can be searched.

A source will not preview

Some websites prevent embedded previews. Your source link remains available, and you can open it in the original website or app.

Local AI

Ollama settings are for local development only. Public Release builds keep OCR and normal saving active without attempting to connect to Ollama.

Deleting data

Delete one Memory from its detail screen, or choose “Delete all local data” in Profile. Deleting a Board does not delete its Memories.
